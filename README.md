# Prediksi Kepadatan Peserta Didik SD Menggunakan Algoritma Random Forest

Proyek ini merupakan bagian dari Tugas Besar Applied Machine Learning. Studi ini bertujuan untuk mengklasifikasikan tingkat kepadatan peserta didik SD pada setiap provinsi di Indonesia berdasarkan data resmi dari Kemendikdasmen tahun 2024. Algoritma Random Forest digunakan karena stabil, akurat, dan cocok untuk data tabular.

---

## 📌 Tujuan Proyek
- Melakukan pembersihan dan pengolahan data peserta didik (Negeri, Swasta, Total).
- Mengklasifikasikan provinsi ke kelas Padat atau Tidak Padat.
- Melatih model Machine Learning menggunakan Random Forest.
- Mengevaluasi performa model menggunakan akurasi dan confusion matrix.
- Menyediakan model yang dapat digunakan untuk prediksi manual pada data baru.

---

## 📊 Dataset
Dataset berasal dari portal data resmi Kemendikdasmen RI.

**Kolom utama dataset:**
- Provinsi  
- Jumlah Peserta Didik Negeri  
- Jumlah Peserta Didik Swasta  
- Total Peserta Didik  
- Label (hasil pengolahan)
